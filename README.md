# La Commissione IA del Comune

Laboratorio decisionale sull’AI Act per dipendenti della Pubblica Amministrazione italiana.

## Come si svolge

In piccoli gruppi, i partecipanti ricevono le proposte tecnologiche di un Comune immaginario. Per ogni fascicolo aprono documenti, pongono domande, scoprono un imprevisto e deliberano tra **approvare con condizioni**, **sospendere per istruttoria** e **respingere**. Possono inserire una breve motivazione, poi confrontarla con l'orientamento didattico e salvare il verbale finale.

La modalità **rapida** presenta 4 fascicoli (circa 25 minuti); la modalità **completa** ne presenta 6 (circa 40 minuti). In entrambe è incluso il caso di social scoring.

## Modalità formatore

Un interruttore nella schermata iniziale attiva il conteggio **manuale** dei voti comunicati dalle squadre. Il conteggio non aggrega dispositivi diversi e non utilizza un server. Il timer può essere avviato, messo in pausa e reimpostato.

## Caricamento su GitHub Pages

Caricare `index.html` nella cartella principale del repository. In **Settings → Pages**, selezionare **Deploy from a branch**, branch `main`, directory `/(root)`. Non occorrono altri file, API, chiavi, build o database. Il `README.md` è facoltativo.

## Privacy

L'app funziona nel browser: nessuna chiamata a API o raccolta centralizzata di dati. Le risposte rimangono in memoria fino alla chiusura/ripartenza della pagina. Il file `.txt` viene generato localmente. Si raccomanda di utilizzare nomi di squadre e non nominativi personali.
